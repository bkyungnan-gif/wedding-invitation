# 모바일 청첩장 템플릿 (초보자용)

## 가장 쉬운 사용법

1. 이 폴더의 파일을 모두 유지하세요.
2. `config.js` 파일을 메모장으로 엽니다.
3. `신랑 이름`, `신부 이름`, 날짜, 예식장, 주소를 수정합니다.
4. 사진을 `assets` 폴더에 넣고 `cover.jpg`, `gallery-01.jpg` 등의 이름으로 저장합니다.
5. GitHub 저장소에 폴더 안의 파일과 `assets` 폴더를 업로드합니다.
6. 저장소의 **Settings → Pages → Deploy from a branch → main → /(root) → Save**를 선택합니다.
7. 잠시 기다린 뒤 표시되는 주소를 열어 확인합니다.

## 사진 파일 이름

- 대표 사진: `assets/cover.jpg`
- 갤러리: `assets/gallery-01.jpg`부터 `assets/gallery-05.jpg`

사진을 준비하지 않았다면 나중에 넣어도 됩니다. 이미지 파일이 없는 항목은 페이지에서 자동으로 숨겨집니다.

## 지도 연결

네이버 지도 또는 카카오맵에서 예식장 위치를 찾고 공유 링크를 복사한 뒤 `config.js`의 `naverMapUrl` 또는 `kakaoMapUrl` 따옴표 안에 붙여넣습니다.

## 계좌와 연락처

실제 공개하기 직전에만 입력하세요. 입력한 정보는 웹사이트를 보는 사람에게 공개됩니다. 계좌 정보는 필수 사항이 아니며 비워두면 해당 영역이 숨겨집니다.

## 알아둘 점

- 이 템플릿은 정적 웹사이트이며 GitHub Pages에서 무료로 배포할 수 있습니다.
- 참석 여부 응답을 저장하는 기능은 포함되어 있지 않습니다.
- 지도 버튼은 URL을 입력했을 때만 표시됩니다.
- 날짜는 `YYYY-MM-DD` 형식으로 입력하세요. 예: `2028-10-21`
